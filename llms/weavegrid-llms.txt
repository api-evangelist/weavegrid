# WeaveGrid

> WeaveGrid builds grid-orchestration software for electric utilities. Its DISCO
> (Distribution-Integrated System Capacity Orchestration) platform ingests vehicle telematics and
> cloud-connected device data and sends hyper-local charging and dispatch signals to EVs, home
> batteries, smart thermostats and other flexible loads, so utilities can absorb EV load growth

## API surface — read this first

WeaveGrid has **no public developer program**. There is no developer portal, no API reference, no
published OpenAPI/AsyncAPI/GraphQL specification, no SDK, no CLI, no MCP server and no A2A agent card.
An agent cannot integrate with WeaveGrid from public material alone.

A partner API does exist and is marketed to aggregators, OEMs and device manufacturers, but it is
reached only through a commercial conversation:

- Partner API host: https://api.weavegrid.com (FastAPI / uvicorn)
- Generated OpenAPI document: https://api.weavegrid.com/openapi.json — HTTP 401, `WWW-Authenticate: Basic`
- Swagger UI: https://api.weavegrid.com/docs — HTTP 401, `WWW-Authenticate: Basic`
- Access route: "Become a partner" contact form at https://www.weavegrid.com/partners

The specification therefore EXISTS in machine-readable form; it is simply not published. Requesting
that WeaveGrid publish the contract while keeping credential issuance behind the partner form is the
single highest-value change available to this profile.
